# กลยุทธ์ Asian Range Breakout สำหรับทองคำ (XAUUSD): ผลวิจัยและสเปก EA

> สถานะ: วิจัยเสร็จแล้ว · ข้อมูล M1 ปี 2014-01 ถึง 2026-09 · EA: `ea/XAU_AsianRangeBreakout.mq5`
> **ข้อสรุปหลัก: breakout มี "ข้อได้เปรียบเชิงทิศทาง" จริงแต่เล็กมาก ใกล้เคียงกับต้นทุนการเทรด
> ยังพิสูจน์ไม่ได้ว่ามีกำไรหลังหักต้นทุน ควรใช้ EA ในฐานะการทดลอง (demo / ความเสี่ยงต่ำ) เท่านั้น**

## 1. สรุปสั้น

| คำถาม | คำตอบจากข้อมูล |
|---|---|
| กรอบช่วงเอเชียโดนเบรกช่วงลอนดอนบ่อยไหม | บ่อยมาก 97.8% ของวัน (IS 2014–2021) |
| เบรกแล้ววิ่งต่อจริงไหม | จริง แต่นิดเดียว: โอกาสวิ่ง +1 เท่าความกว้างกรอบก่อนย้อน −1 เท่า = **53%** (ถ้าสุ่มจะได้ 50%) |
| ขนาดของข้อได้เปรียบ | ก่อนหักต้นทุนราว **+0.10R ต่อเทรด** (t 2.9) หรือประมาณ $0.5/oz ต่อเทรด |
| ต้นทุนต่อเทรด (spread + ค่าคอม + slippage) | ประมาณ **$0.47/oz ≈ 0.09R** จึงกินกำไรไปเกือบหมด |
| เทรดสวนเบรก ("Judas swing", stop hunt) | **ขาดทุนชัดเจน** ทั้ง 1,316 แบบที่ทดสอบ แม้ยังไม่หักต้นทุน |
| filter หลอกเบรก (buffer, รอแท่งปิดยืนยัน) | **ไม่ช่วย** มีแต่ทำให้ได้ราคาเข้าที่แย่ลง |
| สิ่งเดียวที่ยังเหลือขอบกำไรหลังหักต้นทุน | เทรดเฉพาะวันที่กรอบเอเชีย **กว้าง** เทียบกับ ATR (≥ 0.30–0.40 × ATR14) |
| ผลทดสอบข้อมูลที่เก็บปิดไว้ (2024–2026) | บวกเล็กน้อย (+0.05 ถึง +0.07R) แต่ **ยืนยันทางสถิติไม่ได้** และ filter ไม่ได้ดีกว่าแบบไม่มี filter |
| คาดการณ์ใช้จริงอย่างสมเหตุสมผล | **ประมาณ 0 ถึง +0.03R ต่อเทรด** (ในย้อนหลังช่วงที่ใช้ปรับเห็น +0.12R) |

**แปลเป็นผลตอบแทน:** ถ้าเสี่ยง 0.5% ต่อเทรด และเทรดราว 80–120 ครั้งต่อปี ผลที่คาดได้คือราว **0–2% ต่อปี**
ขณะที่ drawdown ระดับ 15–25R (7–12% ของพอร์ต) เกิดขึ้นได้ตามปกติ กลยุทธ์นี้จึง **ไม่ใช่ระบบทำเงินที่ "เสถียร"** อย่างที่โฆษณาไว้

## 3. วิธีการวิจัย (ทำไมถึงเชื่อถือได้)

**ข้อมูล**
- ใช้ XAUUSD M1 ปี 2014-01 ถึง 2026-09 จาก HistData (ประมาณ 4.5 ล้านแท่ง)
- ปรับเวลาเป็น UTC โดยอิงช่วงตลาดหยุดประจำวัน 17:00–18:00 น. นิวยอร์ก แล้วตรวจกับ Dukascopy 429 วันได้ตรงทั้งหมด (พบว่าเอกสารของ HistData ระบุเขตเวลาผิด)
- วันที่ข้อมูลขาด (ส่วนใหญ่ในปี 2023) เติมด้วยข้อมูล Dukascopy
- ใช้ spread จริงจาก Dukascopy แยกตามปีและชั่วโมง: $0.25–0.40 ในปี 2014–2024 และ $0.55–0.75 ในปี 2025–26

**การจำลองการส่งคำสั่ง (ตั้งแบบระมัดระวัง)**
- Buy Stop ทำงานเมื่อราคา ASK แตะ ส่วน Sell Stop ทำงานเมื่อ BID แตะ เหมือน MT5
- ถ้ามี gap ได้ราคาที่แย่กว่า
- ถ้า SL กับ TP อยู่ในแท่งเดียวกัน ถือว่าโดน SL ก่อน
- คิดค่าคอม $7/lot และ slippage $0.05 ต่อการ fill

**การแบ่งข้อมูล**

| ช่วง | ใช้ทำอะไร |
|---|---|
| IS 2014–2021 | ค้นหาและปรับค่า |
| VAL 2022–2023 | ตรวจตัวเลือกไม่กี่ตัว |
| **HOLDOUT 2024–2026** | **ปิดไว้ตลอด เปิดดูครั้งเดียวหลังล็อกกลยุทธ์แล้ว** |

**การตรวจสอบ**
- engine ถูก audit เจอบั๊ก 9 จุด แก้ครบพร้อมเทสต์ (ปัจจุบันเทสต์ผ่าน 26/26)
- เทียบผลกับการสุ่มทิศทาง (null test)
- ทำ reality check แบบ bootstrap และคำนวณ Deflated Sharpe
- จำลองต้นทุนที่แย่ลง (stress test) และตรวจกับข้อมูล tick จริง

## 4. สิ่งที่ค้นพบ แยกตามแกน

1. **ช่วงเวลา** กรอบ 00:00–05:00 น. ลอนดอนดีกว่า 00:00–07:00 น. เล็กน้อย ควรถือถึง 18:00–21:00 น. และ breakout ของช่วงนิวยอร์ก (กรอบเช้าลอนดอน) ไม่มี edge เลยจาก 771 แบบที่ลอง
2. **การเข้าออเดอร์** ใช้ Stop order ที่ขอบกรอบพอดี (buffer 0) ดีที่สุด การ fade หรือ Judas ขาดทุนทุกแบบ ส่วนการรอแท่งปิดยืนยันทำให้ edge ลดลง
3. **การออกออเดอร์** ไม่ตั้ง TP ดีที่สุด TP 1–2R ทำให้แย่ลง ใช้ SL กว้าง (1 เท่าความกว้างกรอบ) และปิดตามเวลา กำไรทั้งหมดมาจาก **วันเทรนด์ใหญ่ไม่กี่วัน** (10% ของเทรดที่ดีที่สุดสร้างราว 50–60% ของ R ฝั่งบวกทั้งหมด)
4. **filter วันเทรด**
   - กรอบ **กว้าง** ≥ 0.30–0.40 × ATR14 เป็น filter เดียวที่เห็นผลสม่ำเสมอ เพราะต้นทุนต่อ R ลดครึ่ง และ follow-through ก็ดีกว่า
   - กรอบ **แคบ** (NR7/compression) กลับแย่ที่สุด ตรงข้ามกับตำราของ Crabel
   - filter ตามเทรนด์ วันในสัปดาห์ และวัน NFP ไม่ช่วย
5. **ต้นทุน** เป็นตัวตัดสินทุกอย่าง ต้นทุน $0.1/oz ที่เพิ่มขึ้น เท่ากับ edge ลดลงราว 0.02R ต่อเทรด **SL แคบจึงเป็นกับดัก** เพราะต้นทุนต่อ R เพิ่มตาม 1/SL
6. **งานวิจัยตีพิมพ์** ORB ที่ได้ผลในหุ้นหรือ QQQ อาศัยต้นทุนต่ำมาก momentum ระหว่างวันในทองมีจริงแต่เล็ก (~0.7 bp/วัน) ความลำเอียงทิศทางช่วง London Fix หายไปตั้งแต่เปลี่ยนเป็นระบบ IBA auction ปี 2015 และประสิทธิภาพของ breakout ลดลงเรื่อย ๆ ตามเวลา (decay)

## 5. สเปกกลยุทธ์ (ล็อกไว้ก่อนเปิดข้อมูล holdout)

เวลาทั้งหมดเป็น **เวลาลอนดอน** (ปรับ GMT/BST อัตโนมัติ) เทียบเวลาไทยได้ดังนี้

| เวลาลอนดอน | เวลาไทย (ฤดูร้อน BST, ปลาย มี.ค.–ปลาย ต.ค.) | เวลาไทย (ฤดูหนาว GMT) |
|---|---|---|
| 00:00 เริ่มกรอบ | 06:00 | 07:00 |
| 05:00 จบกรอบ / วางออเดอร์ | 11:00 | 12:00 |
| 12:00 ยกเลิกออเดอร์ที่ยังไม่ fill | 18:00 | 19:00 |
| 20:00 ปิดสถานะ | 02:00 (วันถัดไป) | 03:00 (วันถัดไป) |

| ขั้น | กฎ |
|---|---|
| 1. กรอบราคา | High/Low (BID) ของแท่ง M1 ตั้งแต่ **00:00 ถึง 05:00 น.** ลอนดอน |
| 2. ATR14 | ค่าเฉลี่ย True Range ของ 14 วันทำการก่อนหน้า (แท่งรายวันตามวันลอนดอน) |
| 3. เงื่อนไขวันเทรด | **ความกว้างกรอบ ≥ 0.35 × ATR14** (FALLBACK) หรือ ≥ 0.30 × ATR14 และ ATR14 ≤ ค่าเฉลี่ย 20 วันของตัวเอง (PRIMARY) |
| 4. เข้าออเดอร์ | เวลา 05:00 น. วาง **Buy Stop ที่ High และ Sell Stop ที่ Low ของกรอบ** (ไม่มี buffer) ตัวหนึ่ง fill แล้วลบอีกตัว (OCO) ไม่มีออเดอร์ใหม่หลัง 12:00 น. |
| 5. Stop Loss | **1 เท่าความกว้างกรอบ วัดจากราคาที่ fill จริง** |
| 6. Take Profit | **ไม่มี** |
| 7. ปิดสถานะ | **20:00 น. ลอนดอน** (ปิดก่อนถ้าวันนั้นตลาดสหรัฐปิดเร็ว และไม่ถือข้ามสุดสัปดาห์) |
| 8. จำนวนเทรด | สูงสุด 1 เทรดต่อวัน |
| 9. ขนาด lot | ความเสี่ยง 0.25–0.5% ต่อเทรด = % ความเสี่ยง × ทุน ÷ (ระยะ SL × 100 oz) ปัดลง ถ้าได้ต่ำกว่า lot ขั้นต่ำให้ข้ามวันนั้น |

**แนะนำ FALLBACK** (EA ตั้งเป็นค่าเริ่มต้นไว้แล้ว) เหตุผลทั้งหมดมาจากข้อมูล *ก่อน* เปิด holdout:
- t-stat สูงกว่า (2.63 เทียบกับ 1.94)
- family-wise p ดีกว่า (0.055 เทียบกับ 0.16)
- ข้อมูล VAL เป็นบวกทั้งสองปี
- ไม่ต้องพึ่ง filter ATR regime ที่อ่อนไหวต่อความต่างของข้อมูลแต่ละโบรกเกอร์

กฎคัดเลือกที่ประกาศไว้ล่วงหน้าเลือก PRIMARY เพราะวิธีให้คะแนนแบบเฉลี่ยกับค่าข้างเคียง จึงเก็บ PRIMARY ไว้เป็นตัวเลือกด้วย

### วิธีอ่านผล holdout อย่างตรงไปตรงมา

- ทั้งสองแบบเป็นบวก แต่ **แยกไม่ออกทางสถิติระหว่าง "มี edge" กับ "ไม่มี edge"**
  - ช่วงความเชื่อมั่น 90% ของ FALLBACK คือ −0.014 ถึง +0.162R
  - ช่วงความเชื่อมั่น 90% ของ PRIMARY คือ −0.076 ถึง +0.177R
- **filter ไม่ได้ช่วยในปี 2024–26** เพราะแบบไม่มี filter ก็ได้ +0.050R พอ ๆ กัน
- **ผลบวกส่วนใหญ่มาจากต้นทุนที่ถูกลงเมื่อเทียบกับ R** ปี 2025–26 ทองราคา $3,500–4,500 กรอบเอเชียกว้าง $25–55 ขณะที่ต้นทุนราว $0.7–1.0/oz ต้นทุนจึงเหลือเพียง 0.02–0.03R (ปี 2014–21 อยู่ที่ 0.08R) ถ้าต้นทุนกลับไปอยู่ระดับเดิม PRIMARY จะติดลบ ส่วน FALLBACK เหลือราว +0.03R
- ทีมตรวจ 3 ด้าน (สถิติ, การส่งคำสั่งจริง, ความทนทานต่อสภาพตลาด) ให้คำตัดสินเป็น **"weak" ทั้งสามด้าน**

## 7. ความเสี่ยงสำคัญ

1. **กำไรพึ่งวันเทรนด์ใหญ่ไม่กี่วัน** ถ้าตัด 10 เทรดที่ดีที่สุดใน IS ออก PRIMARY เหลือ +0.009R และ FALLBACK เหลือ +0.054R ถ้าพลาดเทรดเหล่านั้นเพราะ VPS ดับหรือ spread กระโดดตอนเข้า ผลทั้งปีหายได้เลย
2. **ปีที่เงียบเป็นเรื่องปกติ** ปี 2015, 2016, 2018 และ 2019 ผลแทบเป็น 0 และแพ้ติดกัน 10 ไม้เคยเกิดมาแล้ว
3. **Slippage ของ SL ตอนข่าว** จากข้อมูล tick จริง SL ที่โดนตอนข่าว 08:30 น. นิวยอร์ก (19:30 หรือ 20:30 น. เวลาไทย) ไหลเฉลี่ย $0.7 สูงสุดถึง $4.5 ทำให้ edge หายไปอีกราว 0.02R ต่อเทรด
4. **ช่วงทองขาขึ้นแรง** ในอดีตกลยุทธ์นี้ทำได้ไม่ดีเมื่อทองขึ้นแรง (> +25%/ปี) ส่วนผลดีส่วนใหญ่อยู่ในช่วงทองทรงตัวหรือขาลง
5. **ข้อมูลแต่ละโบรกเกอร์ต่างกัน** High/Low และ ATR ต่างกันเล็กน้อย ทำให้วันที่ผ่าน filter เปลี่ยนไป 2–8%
6. **ยืนยันด้วยการเทรดจริงไม่ได้ในเวลาอันสั้น** edge +0.05R ต้องใช้หลายสิบปีจึงจะพิสูจน์ได้ทางสถิติ ผลจริงจะใช้ได้แค่จับความผิดปกติด้านต้นทุนหรือการส่งคำสั่ง

## 8. วิธีใช้ EA (`ea/XAU_AsianRangeBreakout.mq5`)

### 8.1 เงื่อนไขบัญชี
- บัญชีแบบ **ECN/Raw** ค่าคอม ≤ $7/lot ต่อรอบ
- **ต้นทุนรวมต่อเทรด (spread + ค่าคอม + slippage) ต้องไม่เกินราว 5% ของความกว้างกรอบเอเชียโดยเฉลี่ย** ที่ราคาทองปัจจุบัน (กรอบ $25–55) คือต้นทุนไม่ควรเกิน ~$1.0–1.5/oz
- **ทุนขั้นต่ำ:** lot ขั้นต่ำ 0.01 = 1 oz ดังนั้นความเสี่ยงต่ำสุดต่อไม้ = ความกว้างกรอบ ≈ $25–55
  - เสี่ยง 0.5% ต้องมีทุน **~$10,000 ขึ้นไป**
  - เสี่ยง 1% ต้องมี **~$5,000 ขึ้นไป**
  - ทุนน้อยกว่านี้ EA จะข้ามหลายวัน เพราะออกแบบให้ไม่เสี่ยงเกินที่ตั้งไว้

### 8.2 ตั้งค่าเวลาเซิร์ฟเวอร์ (สำคัญที่สุด)
- `InpServerClock` ค่าเริ่มต้นคือ **GMT+2 ฤดูหนาว / GMT+3 ฤดูร้อน ตาม DST สหรัฐ** ซึ่งเป็นแบบที่โบรกเกอร์ทองส่วนใหญ่ใช้
- ตรวจกับโบรกเกอร์ของคุณ: ถ้าเวลาเซิร์ฟเวอร์เปลี่ยนตามยุโรปให้เลือก EU DST ถ้าไม่เปลี่ยนเลยให้เลือก Fixed
- ตอนเริ่ม EA จะพิมพ์เวลา Server / UTC / London ใน log ให้เทียบกับเวลาลอนดอนจริง ถ้าผิด 1 ชั่วโมง ทุกอย่างจะเลื่อนตาม
- ใน Strategy Tester ห้ามใช้โหมด Auto เพราะ TimeGMT() ใน tester ไม่ถูกต้อง

### 8.3 ขั้นตอนก่อนใช้เงินจริง
1. **Compile ใน MetaEditor** EA นี้ผ่านการตรวจโค้ดด้วยตาและทดสอบตรรกะเทียบกับ engine ด้วย Python แล้ว **แต่ยังไม่เคย compile จริง** (ไม่มี MetaEditor ในสภาพแวดล้อมนี้) ถ้าเจอ error ให้ส่งข้อความ error มาได้เลย
2. ตั้ง `Max bars in chart` ≥ 100,000 และต้องมีประวัติ M1 อย่างน้อย ~70 วันก่อนวันเริ่มทดสอบ เพราะ EA สร้าง ATR จากแท่ง M1 ตามวันลอนดอน
3. Strategy Tester โหมด **"Every tick based on real ticks"** ช่วง 2022–2026 บนข้อมูลของโบรกเกอร์ ผลควรใกล้ตารางในข้อ 6 (ไม่ตรงทุกไม้เพราะคนละแหล่งข้อมูล)
4. **Demo 3 เดือน** บันทึก spread, slippage ตอนเข้า และ slippage ของ SL ทุกไม้
5. ถ้าต้นทุนจริงอยู่ในเกณฑ์ข้อ 8.1 ค่อยเริ่มเงินจริงที่ **0.25–0.5% ต่อเทรด**

### 8.4 กฎหยุดระบบ (ทำเองด้วยมือ เพราะ EA ยังไม่มี kill switch อัตโนมัติ)
- **หยุดทันที** เมื่อ drawdown สะสมถึง **25R** (≈ 12.5% ที่ความเสี่ยง 0.5%)
- **ลดความเสี่ยงครึ่งหนึ่งแล้วทบทวน** เมื่อผลเฉลี่ย 100 เทรดล่าสุดต่ำกว่า −0.10R และหยุดถ้าต่ำกว่า −0.15R
- **หยุด** ถ้าต้นทุนเฉลี่ยจริง 30 เทรดล่าสุดเกินงบในข้อ 8.1 หรือ slippage ของ SL เฉลี่ยเกิน $0.5
- **ครบ 200 เทรด** (ราว 2 ปี) ถ้าผลรวมยัง ≤ 0 ให้เลิกใช้
- **ห้ามปรับพารามิเตอร์ตามผลเทรดจริง** เพราะข้อมูล 1–3 ปีแยก edge +0.12R ออกจาก 0 ไม่ได้ การปรับหลัง drawdown คือการ overfit กับ noise

## 9. สิ่งที่ไม่ควรทำ (ทดสอบแล้วแย่)

- เทรดสวนเบรก หรือ fade / Judas swing / turtle soup
- ตั้ง SL แคบ (< 0.75 เท่าความกว้างกรอบ) หรือ TP 1–2R
- เลือกเทรดเฉพาะวันที่กรอบแคบ (NR7 / compression)
- breakout กรอบเช้าลอนดอนช่วงนิวยอร์กเปิด
- ใส่ martingale หรือเพิ่ม lot หลังแพ้ เพราะกลยุทธ์นี้แพ้บ่อย (win rate 45%) และพึ่งเทรดใหญ่ไม่กี่ไม้
- ใช้บัญชี Standard ที่ spread กว้าง
